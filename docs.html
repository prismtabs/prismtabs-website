Manual

Everything PrismTabs does, in the order you'll use it.

Getting started

Install PrismTabs from the JetBrains Marketplace inside your IDE: Settings → Plugins → Marketplace, search "PrismTabs", click Install, then restart the IDE if prompted.

PrismTabs needs no setup beyond installation. The moment it's enabled you can right-click any open editor tab to start colouring it.

Requirement: IntelliJ Platform 2024.2 or newer. See Compatibility for which IDEs that covers.

Licensing & the free trial

PrismTabs licensing runs in three stages:

  • Day 0 — install. No card, and no licence key to enter.
  • Days 1–30 — everything unlocked. Every install gets the complete Pro feature set, free, for the first 30 days. Nothing is held back during the trial.
  • Day 31 onward — Free, or $9/year. Subscribe to keep the Pro features, or carry on indefinitely with the Free tier below.

The split between the two tiers is feature-based, never a cap on how many groups you can make:

  • Free — assigning tabs to the 8 preset colours, unlimited named groups (create, rename, recolour), persistence across restarts, and assignments that follow a file through a rename or move.
  • Pro — the PrismTabs tool window, hide/show, active-group auto-join, and palette editing.
Never a hard lockout. When the trial ends or a subscription lapses, PrismTabs simply drops back to the Free tier — your existing group assignments, names, and colours are untouched, and Pro features come straight back the moment you subscribe. Nothing is deleted and nothing stops working outright.

The subscription is billed through the JetBrains Marketplace. See Pricing for the full breakdown.

Assigning a tab to a group

Right-click any editor tab. The first item in the context menu is Tab Group…, which opens the colour swatch popup:

  • Click a preset dot — the 8 dots sit under a New Group heading, and clicking one starts a new group: you pick the colour here, then name it. The name field is pre-filled with the colour's own label (e.g. "Blue"), so taking the default is a single keystroke. Cancelling the name prompt aborts the whole flow — no group is created and nothing is assigned. Every click makes a fresh group, so clicking the same colour on two different tabs gives you two separate groups; to add a tab to a group you already have, use Add to Group….
  • Add to Group… — lists your existing groups, each with its colour dot; pick one to add the tab to it. If moving the tab empties the group it was in, PrismTabs offers to delete that now-empty group.
  • Manage Groups… — shown once at least one group exists; opens the rename, recolour, active-group, and delete actions covered in Working with groups.
  • Remove from Group — only shown when the tab is currently assigned; clears the assignment and the tint. If that was the group's last member, PrismTabs offers to delete the empty group.

Working with groups

Open Tab Group… on any editor tab, then choose Manage Groups… — it appears as soon as you have at least one group — to pick a group and act on it:

  • Rename… — change the group's display name.
  • Recolour… — pick a new preset colour; every member tab repaints immediately.
  • Mark as Active Group / Clear Active Group — see Active groups.
  • Delete Group — asks for confirmation first, then clears the assignment from every member tab (the files themselves are untouched).

Rename, recolour and delete are also available from the PrismTabs tool window, without going through a tab's context menu — along with hide/show, which only the tool window offers. Marking a group active is the one action that lives only in the popup.

Active groups Pro

Mark one group active and every file you open afterwards joins it automatically — no assigning each tab by hand. The active group is labelled (active) wherever it appears in the popup.

The active group doesn't survive a restart, by design. An assignment is something you explicitly chose; "active" is closer to a recording toggle you'd likely forget was on. Restarting the IDE always clears it, so files never get auto-coloured for a reason you can no longer see.

The PrismTabs tool window Pro

Open the PrismTabs stripe on the right-hand edge of the IDE window (or find it under View → Tool Windows → PrismTabs). It lists every group with its colour dot, name, member count, and whether it's hidden. A toolbar and matching right-click context menu offer Hide/Show Group, Rename…, Recolour…, and Delete Group for the selected group. Double-clicking a row is a shortcut for Hide/Show.

The tool window is where group management lives by design: it keeps everything a group needs — colour, membership, hidden state, and actions — in one dedicated place, so the editor tab strip stays as it is and just carries the group colours.

The list updates live — a group created from the swatch popup on another tab shows up here immediately, no need to reopen the panel.

Hiding & showing Pro

PrismTabs doesn't collapse a group into an in-strip chip; instead, hiding means "close and remember":

  • Hide Group closes every open tab belonging to the group and records exactly which files were open, in order.
  • Show Group reopens each of those files, in the same order, without changing focus away from what you're already looking at.

Use it to get a crowded group out of the way without losing track of what was open in it — the group stays listed in the tool window (marked "hidden") the whole time.

A hidden group is never held hostage. If your trial or subscription ends while a group is hidden, the tool window still offers a one-click "reopen the tabs of your hidden groups" — outside the paywall, precisely because hiding is what closed them.

Persistence & renames

Group assignments and hidden state are stored per-project and survive an IDE restart. They also follow a file through a rename or a move, including files nested inside a renamed or moved directory — you won't lose a tab's colour just because you reorganised your project.

Deleting a file (or a directory of them) drops the matching assignments rather than leaving a group pointing at something that no longer exists. If that empties a group, PrismTabs offers to delete it — the group itself is never removed without asking.

Compatibility

PrismTabs depends only on com.intellij.modules.platform, so it isn't tied to one product — it runs in IntelliJ IDEA, WebStorm, PyCharm, GoLand, PhpStorm, Rider, RubyMine, CLion, DataGrip, Android Studio, and any other IDE built on the same platform, from 2024.2 onward. It's tested against both the classic and the Islands tab painters, in light and dark themes alike.

FAQ

Why does an unselected tab look more faded than the selected one?

IntelliJ draws unselected editor tabs at roughly half tint strength against the background, so a group colour reads more softly there than on the active tab. The palette's dark presets are deliberately saturated enough to stay clearly visible even after that blend.

Does a colour follow the tab or the file?

The file. If the same file is open in two split editors, both tabs show the same colour — the platform's colour API is keyed on the file, not on an individual tab instance.

Is there a collapsible group bar in the tab strip, like browser tab groups?

No — IntelliJ provides no way to draw a widget that spans or collapses a run of editor tabs. PrismTabs shows a group in two places instead: the group's colour on each of its member tabs, and the PrismTabs tool window, which lists the group as a unit — name, colour, member count, and hidden state — with rename, recolour, delete, and hide/show. Hiding a group from the tool window closes its tabs and reopens them on demand, which covers most of what collapsing a browser group is for.

Can tab text colour change along with the background?

No. The relevant platform API for tab foreground colour is experimental and tied to file status, not to PrismTabs' groups, so only the tab background is themeable.

What happens to a group's files when I delete the group?

Only the assignment is removed — every member tab loses its colour and its group membership, but the files themselves are completely unaffected. Deleting a group always asks for confirmation first.

Is there a one-time, perpetual licence option?

No — PrismTabs Pro is a $9/year subscription only. See Licensing & the free trial for what stays free without one.

What happens when the 30-day trial ends?

Without an active subscription, PrismTabs drops to the Free tier: the PrismTabs tool window, hide/show, active-group auto-join, and palette editing become unavailable until you subscribe. Nothing is deleted, and the core tab-colouring workflow keeps working.

What happens if my Pro subscription lapses after a year?

The same downgrade as an expired trial — back to the Free tier, not a frozen or crippled state. Renewing brings the Pro features straight back with your existing groups and assignments intact.

I’ve found a bug, or I want to request a feature. Where do I go?

The PrismTabs feedback tracker on GitHub, which covers both, for every edition — Free, Pro and the trial alike. Anything touching a purchase (licence keys, invoices, refunds) should go to yendrrek@protonmail.com instead, since the tracker is public.
