Features

Everything you'd expect from browser-style tab groups, adapted to how IntelliJ tabs actually work

IntelliJ has no public API for an in-strip group chip, so PrismTabs doesn't fake one — it colours tabs directly and gives groups a proper home in a dedicated tool window.

One right-click away

Right-click any editor tab for a colour swatch popup: 8 presets, "Add to Group…", or "New Group…" for a custom name.

Named, reusable groups

Group tabs under a name, not just a colour. Rename, recolour, or delete a group any time from the popup.

Active-group auto-join

Mark a group active and every file you open joins it automatically — until you deactivate it.

A real Tab Groups panel

A right-hand tool window lists every group with its colour, member count, and collapsed state.

Collapse, then expand

Collapsing a group closes its tabs and remembers them; expanding reopens every one, in order.

Survives restarts & renames

Assignments and collapsed state persist across restarts, and follow a file through a rename or move.

Palette

Eight presets, tuned for both themes — and fully editable

Every colour ships with a light and a dark variant, measured for contrast against IntelliJ's own tab painter rather than picked by eye. Rename any preset or repaint it under Settings → Tools → PrismTabs.

How it works

Three steps, no configuration required

PrismTabs works out of the box with sensible defaults — the palette settings are there for when you want them, not because you need them.

Right-click a tab

Open the colour swatch popup from any editor tab's context menu — no shortcut to memorise.

Pick a colour or group

Click a preset for a quick shared group, or use "New Group…" to pick a colour and give it a name.

Manage from the tool window

Open "Tab Groups" on the right-hand stripe to rename, recolour, collapse, or delete a group.

Compatibility

Built on the IntelliJ Platform, not one IDE

PrismTabs depends only on com.intellij.modules.platform, so it runs anywhere that module ships.
